04. Electronegativity

Pauling-scale electronegativity laid out across the periodic table as a continuous color heatmap. Each cell is tinted from indigo (very electropositive, e.g. Cs, Fr) through teal and pale yellow up to deep red (F, the most electronegative element). Hover any cell for the Pauling EN value, group/period, and element category.

TagsChemistry · Periodic Table · Heatmap
Data103 elements with published Pauling EN values
Open Project →

05. Perovskite Octahedral Tilt

Interactive 3D walkthrough of Glazer octahedral-tilt theory. Start from the ideal cubic Pm3̄m framework, then tilt the corner-sharing BX₆ octahedra about each axis (in-phase + / anti-phase −) and watch the Glazer symbol, space group, and crystal system update live. Click any real halide-perovskite phase (CsPbI₃, FAPbI₃, CsSnI₃, FASnI₃) to morph the model into it.

TagsChemistry · 3D · Three.js · Perovskite · Symmetry
CoverageGlazer tilt systems · halide-perovskite phase sequences (black vs yellow)
Open Project →

06. Literature Search

Browser-side scholarly search across OpenAlex, Crossref, and arXiv from a single box — with year-range and open-access filters, sorting by relevance / date / citations, reconstructed abstracts, and one-click CSV / BibTeX export. Everything runs client-side; no login required (OpenAlex needs a free API key, pasted once and stored locally).

A structured mechanism-analysis workspace for moving beyond static mind maps: connect observations, competing hypotheses, evidence, constraints, predictions, and experiments with typed relations; compare candidates in matrix and timeline views; and preserve the complete reasoning chain as an editable research record.

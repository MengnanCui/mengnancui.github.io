# 小红书每日简报

用你自己的登录状态，在你的 Mac 上慢速刷小红书网页版发现页（只读，不点赞不评论不关注），
然后让 Claude 写成一篇几分钟读完的文章。

## 第一次使用（约 10 分钟）

打开"终端"，进入这个文件夹，依次运行：

```bash
bash setup.sh        # 1. 安装（只需一次）
./run.sh login       # 2. 弹出浏览器，用手机小红书扫码登录，然后回终端按回车
./run.sh             # 3. 刷一次，生成并自动打开简报
```

想每天自动跑：

```bash
./schedule.sh 12:30  # 每天 12:30 自动刷并打开简报
./schedule.sh off    # 取消
```

## 写文章那一步需要 Claude Code

脚本会调用本机的 `claude` 命令来写简报（用你的 Claude 订阅，不需要 API key）。
没装的话简报会退化成一份未整理的标题列表。安装方法见 https://code.claude.com/docs ，
装完在终端运行一次 `claude` 并登录。

## 可调参数

```bash
./run.sh --screens 20 --details 10   # 下滑 20 屏，点进去读 10 条正文
./run.sh --details 0                 # 只看标题，不点进任何笔记（最保守）
```

## 文件说明

- `digests/`  每次生成的简报（HTML）
- `raw/`      每次抓到的原始数据（JSON）
- `seen.json` 已经看过的笔记，下次不会重复出现
- `browser-profile/` 你的小红书登录状态。**不要发给任何人，不要上传到网上**
- `debug/`    抓取失败时的页面快照，交给 Claude 排查用

## 出问题时

- 提示"没有登录或被要求验证"：重新运行 `./run.sh login`。
- 提示"一条都没抓到"：小红书改版了。在这个文件夹里打开 Claude Code，说
  "抓取失败了，看 debug/ 里的快照，修一下 xhs_digest.py 的选择器"。
- 频繁弹验证码：停用几天，并把 `--screens` 和 `--details` 调小。

## 风险提示

自动化访问违反小红书用户协议。每天 1–2 次、只读、本机网络的情况下风险较低，但不是零。
不要调高频率，不要改成会点赞/评论/关注的版本。

常用晶体结构对照表 Common Crystal Structures

关于本页面

共收录 14 种经典无机晶体结构，涵盖立方 · 四方 · 六方 · 三方 4 大晶系。采用点线（球棍）结构呈现，原子为节点、化学键为连线，框架清晰。每个结构配有可交互三维模型（拖动旋转 · 滚轮缩放 · 双击重置），支持原胞/超胞视图切换。

技术说明 · 这个页面是怎么做出来的

本页是单文件、零构建、零外部请求的静态页面——晶体在浏览器里实时生成：高对称结构按对称性程序化写出，低对称结构内嵌 Materials Project POSCAR 文本就地解析，全程不发起任何网络数据请求。

1. 数据模型与结构选择

核心是一个 CRYSTALS 数组，每个结构是一个对象，含 id、晶系（bravais）、化学式、空间群、文字解说（起源/特征/洞见）、物理性质表、相关结构、图例配色，以及两个渲染函数 buildPrim / buildSuper（原胞 / 超胞）。另一个 BRAVAIS 数组按晶系分组，驱动侧边栏分节。

收录标准是结构化学中最具"原型"意义的无机结构：金属堆积（BCC、FCC）、AB 型（NaCl、CsCl、闪锌矿、纤锌矿、方铅矿）、AB₂/A₂B₃/ABO₃（萤石、金红石、刚玉、钙钛矿、尖晶石）、单质网络（金刚石、石墨）。每个都代表一整族真实材料。

2. 数据来源

  • 晶胞参数与空间群：ICSD 标准晶胞 / 教科书值。
  • 六方 / 三方原子坐标：AFLOW Prototype Encyclopedia 标准原型 + Wyckoff 位（纤锌矿 = B4 / AB_hP4_186_b_b；刚玉 = D5₁ / A2B3_hR10_167_c_e）。
  • 立方结构的分数坐标按对称性直接写出（面心、四面体空隙 ¼¼¼ 等）。

3. 渲染引擎 —— Three.js (r128)

每个 canvas 一个独立 viewer，没有用 OrbitControls 而是自写轻量交互以减少依赖：相机用球坐标 (θ, φ, radius) 表示，鼠标拖动改 θ/φ、滚轮改 radius、双击复位，触屏同逻辑；ResizeObserver 自适应尺寸。

观感采用 VESTA/MP 风格的"影棚"方案：浅色背景 + 半球光（天/地）+ 暖色主光 + 冷色补光；主光开 PCFSoftShadowMap 柔和阴影，配一块只接收阴影的隐形地面（ShadowMaterial）做接触落影；渲染器开 sRGB 输出 + ACES 滤色调映射。

4. 球棍模型与多面体

原子用 MeshStandardMaterial 物理材质的球（金属带金属度反光），配 VESTA/CPK 标准元素配色；化学键是一根圆柱，用四元数 setFromUnitVectors 旋到两原子连线方向。配位型结构还会绘制半透明配位多面体（ConvexGeometry 凸包 + 棱线，仅在配位壳层完整时画）。

不存连接表，而是按距离阈值自动判键（bondAB 连异种离子，bondSelf 连同种网络）。阈值按已知最近邻距离精确卡定，只连真正的键：

结构最近邻cutoff
BCC体对角 a√3/2a×0.93
FCC面对角 a/√2a×0.74
NaCla/2a×0.62
闪锌矿/金刚石a√3/4a×0.46
钙钛矿 Ti–Oa/2a×0.56（出 TiO₆ 八面体）

坐标系：高对称结构用"分数 × a"直接展开；POSCAR 结构则用 fromCell() 以晶格矩阵（行向量为基矢）把分数坐标转笛卡尔，统一按晶胞中心居中，cellBox() 据同一矩阵画出真实的平行六面体晶胞框（立方/四方/六方-菱形通用），fitRadius() 自动按原子云尺寸定相机距离。

5. 页面框架

外观仿 Read-the-Docs / Sphinx（左深色导航 + 右文档区），纯手写 CSS。buildPage() 遍历晶系动态拼出全部 DOM；IntersectionObserver 滚动时高亮当前结构；顶部搜索框按名过滤；原胞/超胞按钮 clearScene() 后重建（超胞即把平铺范围 n 从 1 改成 2）。

6. 工程取舍与已知局限

  • 坐标来源：高对称结构（NaCl、CsCl、闪锌矿、金刚石、萤石、钙钛矿等）用对称性直接写出的理想分数坐标；低对称结构（尖晶石、刚玉、金红石）改为内嵌 Materials Project 真实 POSCAR，经 parsePoscar+晶格矩阵转笛卡尔坐标，因此 MgO₄/AlO₆、TiO₆、AlO₆ 等多面体距离精确。
  • 纤锌矿：MP 给的是 c≈62 Å 的长周期多型，故用其晶格常数（a=3.81, c=6.23, u=0.375）重建标准 2H 单胞。
  • 多面体补全：单胞边缘阳离子的配位壳可能跨晶胞，fromCell 额外生成一圈周期镜像（halo）专供判键/多面体，保证每个多面体都完整闭合。
  • 性能：超胞下可达数百个独立 Mesh（尖晶石超胞约 450 原子），r128 可扛；卡顿时可在「渲染选项」里调低球面精度，或后续改用 InstancedMesh。

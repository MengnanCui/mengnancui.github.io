关于本页面

理想钙钛矿 ABX₃ 是立方 Pm3̄m：BX₆ 八面体角共享成三维网络，A 阳离子填在立方空腔。当 A/B 离子尺寸失配（容忍因子 t<1）时，刚性八面体会协同转动（扭转）以填补空隙，降低对称性。Glazer（1972）用三字母记号 aᵏbᵏcᵏ 系统描述这些扭转。下面的交互扭转台从 Pm3̄m 出发，可实时改变各轴扭转方式并读出空间群；再往下按真实卤化物钙钛矿光伏材料列出常见相，点击即可让模型动画变形过去。

          怎么看出同相 / 反相
          
把 c 轴设为 +，上下两层八面体绕 c 轴转向相同（同相，→ P4/mbm）；设为 −，上下两层转向相反（反相，→ I4/mcm）。这正是必须画 2×2×2 网络的原因——单个八面体看不出层间相位关系。

        


        
        
Glazer 记号详解 · Notation

        
记号形如 a⁺b⁻b⁻，三个字母依次对应绕 [100] · [010] · [001] 三个赝立方轴的扭转：

        

          
要素含义

          
字母 a / b / c扭转幅度。相同字母 = 等幅；不同字母 = 不等幅。

          
上标 ⁰该轴不扭转。

          
上标 ⁺ (同相 in-phase)沿该轴相邻的八面体层同向转动。

          
上标 ⁻ (反相 anti-phase)沿该轴相邻的八面体层反向转动。

        

        
同一层内，角共享约束强制相邻八面体必然反向转动；上标描述的是层与层之间沿该轴的关系。Glazer 原始给出 23 种体系，Howard & Stokes（1998）用群论证明其中 15 种独立。下表是出现在本页材料中的核心体系：

常见钙钛矿结构 · Common Phases

        
以四种典型卤化物钙钛矿光伏材料为例，列出其随温度变化的相序。黑色钙钛矿相（α/β/γ）是角共享八面体网络的不同扭转态——点击「扭转台演示 →」即在浮层窗口中打开扭转台并动画变形到该结构（不跳转、可继续拖拽调参）；黄色 δ 相是面/边共享的一维链状非钙钛矿，无法由网络扭转得到，单独给出示意图。

        

          黑相 vs 黄相
          
同一化学式可结晶为光活性的黑色钙钛矿相（直接带隙、强吸光）或光惰性的黄色非钙钛矿相（宽带隙、绝缘）。室温下不少组分（如 CsPbI₃、FAPbI₃）的热力学稳定相恰是黄相——这正是钙钛矿太阳能电池相稳定性难题的根源。

        

        


        
        
容忍因子 · Goldschmidt Tolerance Factor

        
扭转的几何动因可由容忍因子 t 量化：

        
t = (rA + rX) / [ √2 · (rB + rX) ]

        

          
t 范围结构倾向

          
t ≈ 1.0理想立方 Pm3̄m（a⁰a⁰a⁰），八面体不扭转

          
0.9 ≲ t < 1.0A 位偏大或临界 → 同相/单轴扭转（四方）

          
0.8 ≲ t < 0.9A 位偏小 → 八面体协同倾转填补空腔 → 正交 Pnma（a⁺b⁻b⁻）

          
t < 0.8钙钛矿框架失稳 → 转为非钙钛矿（黄相）链状结构

        

        
直觉：A 阳离子偏小时，立方空腔太大，BX₆ 八面体协同转动「收紧」框架去配位 A，于是出现扭转、对称性下降。把上方扭转台的角度调大，可直观感受框架如何随扭转收缩。


        
        
技术说明

        

          这个页面是怎么做出来的
          

            
单文件、零构建、零数据请求的静态页面，结构在浏览器里实时生成。

            
1. 八面体网络模型

            
B 阳离子置于固定立方格点 (i,j,l)，每个 BX₆ 画成「半透明配位多面体（ConvexGeometry 凸包 + 棱线）+ 6 根 B–X 键 + X 球」。桥连 X 由相邻两八面体共享（按「低指标八面体拥有 +向角」的规则统一计算位置），因此网络恒保持角共享连通。

            
2. 扭转算法

            
格点 (i,j,l) 的八面体绕活动轴 k 转 ±θ，符号规则：与 k 垂直的两指标之和给出层内棋盘式交替 (-1)^(perp)（角共享约束）；上标决定沿 k 的层间关系——+（同相）层间同号，-（反相）层间再乘 (-1)^(沿k指标)。多轴依次叠加旋转。

            
3. 实时对称性判定

            
由三轴 (相位, 幅度) 规范化为标准 Glazer 字符串（零扭转轴排前、等幅共字母），再查内置 KNOWN 表得空间群与晶系；无匹配时标注「低对称·一般扭转」。

            
4. 渲染 / 交互

            
Three.js r128；相机用球坐标(θ,φ,radius)，拖动转视角、滚轮缩放、双击复位、ResizeObserver 自适应；VESTA 风格浅色影棚光照（半球光 + 暖主光 + 冷补光，sRGB + ACES 调映射）。预设演示用 requestAnimationFrame 对扭转角先归零再升到目标（约 560ms），实现平滑变形。

            
5. 已知简化

            
    
              
  • 八面体按刚体绕自身中心转动，共享角取「拥有者」一侧位置——反相单轴严格连通，同相/多轴叠加时桥氧位置为一阶近似（θ≤15° 视觉无碍）。
    • 
              
  • 黄色 δ 相（P6₃/mmc 面共享、Pnma 双链、P6₃cm）为非钙钛矿拓扑，用 SVG 示意而非网络扭转。
    • 
              
  • P3m1（FAPbI₃ 赝立方）为轻微三方极性畸变，演示按近立方处理并加注。

KSPACING ↔ Monkhorst–Pack k-mesh

In VASP and similar codes, KSPACING sets the maximum spacing between adjacent k-points in reciprocal space (units of Å−1). A Monkhorst–Pack (MP) mesh is the integer grid Na × Nb × Nc sampled along the reciprocal lattice vectors. Given the real-space lattice constants a, b, c, the two are linked by:

ks → MP: Ni = max(1, ⌈ 2π / (ks · ai) ⌉)
MP → ks: ksi = 2π / (Ni · ai),   ks = min(ksa, ksb, ksc)

The MP→ks direction reports the per-axis equivalent spacing and the single KSPACING value that, fed back into VASP, reproduces (at minimum) the same mesh. The formula assumes an orthogonal cell where |bi*| = 2π/ai; for highly oblique cells this is approximate.

Quick check

For a cubic cell with a = b = c = 3 Å and KSPACING = 0.3, you should get 7 × 7 × 7. The reverse gives ks ≈ 0.2992 Å−1.

Reference: VASP wiki — KSPACING · Monkhorst & Pack, Phys. Rev. B 13, 5188 (1976).

POSCAR analyzer lattice + KSPACING table

The simple converter above assumes an orthogonal cell. For real crystals — hexagonal, monoclinic, triclinic — the k-mesh depends on the reciprocal-lattice vector magnitudes |bi*|, which need the full lattice including angles. Paste a POSCAR / CONTCAR below and the lattice constants, angles, reciprocal vectors, crystal system, and a KSPACING→mesh table are computed in your browser.

Volume: V = |a1 · (a2 × a3)|
Reciprocal: bi* = 2π (aj × ak) / V  (cyclic i,j,k)
K-mesh: Ni = max(1, ⌈ |bi*| / ks ⌉)

This matches VASP's KSPACING behaviour: each direction is sampled independently with the spacing limited by KSPACING. The reciprocal-lattice norm already encodes the lattice angles, so it works for any cell shape.
